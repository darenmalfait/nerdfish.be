# Nerdfish Review

Meta-skill: orchestrate a prioritized review against all `nerdfish-*` skills.

## Structure

Thin skill — `SKILL.md` only (workflow + skill index). Rule content lives in the
skills this one loads.

## Usage

```bash
npx skills add darenmalfait/nerdfish-agent-skills --skill nerdfish-review
```

Then ask the agent: “nerdfish review” / “analyze my changes with nerdfish skills”.
