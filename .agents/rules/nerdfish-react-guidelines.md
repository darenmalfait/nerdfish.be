# Nerdfish React guidelines

During implementation (not only at review time), follow the
`nerdfish-react-guidelines` skill in `.agents/skills/nerdfish-react-guidelines/SKILL.md`:
load the applicable nerdfish-* and related skills for the files you touch and
apply their rules while editing.

When the user asks for a nerdfish review, audit, or pre-ship pass, use the
**audit** workflow in that skill and report Critical → High → Medium findings.
